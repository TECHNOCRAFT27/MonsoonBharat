# India Weather Heatmap

Visualize India's temperature trends using weather APIs and heatmaps.

## Features
- Current weather data
- Historical temperature analysis
- Interactive heatmap visualization
- Month/year filtering

## Tech Stack
- Python
- Open-Meteo API
- Pandas
- Plotly
- Streamlit
